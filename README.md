# Astrodialogi — калькулятор Асцендента

Отдельный проект для Vercel, не затрагивающий manifest-astrodialogi.

## Настройка
1. Создайте новый репозиторий GitHub и загрузите **содержимое** этой папки (не ZIP как один файл).
2. Импортируйте репозиторий в Vercel (Framework Preset: Other).
3. Добавьте переменную окружения `GEONAMES_USERNAME` — логин GeoNames с включёнными бесплатными web services.
4. Deploy. Проверьте ввод города, расчёт и вариант «Не знаю время рождения».
5. После тестирования подключите домен в настройках Vercel. Для коммерческого сайта проверьте условия тарифного плана Vercel.

## Реализовано
- Swiss Ephemeris, тропический зодиак; 10 планет, скорость/ретроградность, Asc, MC.
- Whole Sign дома, куспиды Плацидуса, базовые натальные аспекты в API.
- GeoNames: поиск городов, timezoneID; IANA zoneinfo для исторических смещений.
- При неизвестном времени: знаки планет и проверка смены знака в течение местного дня, без ASC и домов.
- Неоднозначное и несуществующее местное время при переводе часов отклоняется с предупреждением.

## Ограничения и проверки до публичного запуска
- GeoNames timezoneId и база tzdata могут иметь исторические ограничения (особенно до 1970 г.). Для спорных дат требуется ручная проверка.
- Точность времени рождения влияет на Асцендент; высокие широты могут сделать систему Плацидуса неприменимой.
- Swiss Ephemeris лицензируется отдельно; проверьте соответствие условиям лицензии для публичного/коммерческого использования.
- API не хранит персональные данные рождения, но логи платформы могут содержать метаданные запросов.
- Сравните результаты с контрольными картами до публикации. Для продакшена добавьте rate limiting.
